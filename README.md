# Todo

一个个人任务规划工具，用于追踪学业备考进度。

A personal task planner for tracking academic preparation progress.

## 技术栈 / Tech Stack

- React 19
- Vite
- CSS

## 开始 / Getting Started

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:5173

Open http://localhost:5173 in your browser.

## 构建 / Build

```bash
npm run build
npm run preview
```
